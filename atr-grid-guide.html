AG ATR Grid EA — how it works

This EA is an ATR-based grid trading system. The grid step is calculated from current price volatility (ATR), and as price moves against a position, the EA keeps adding new orders. Each basket has its own profit target and loss limit. This guide explains every setting in plain language.

SECTION 2 · DETAIL MEIN

ATR Grid System

EA ka core logic. Grid Step = ATR × Multiplier — market jitna volatile, grid utna wide. Choppy market mein grid bahut tight na ho jaaye, iske liye Min/Max Gap ek safety clamp lagate hain.
ParameterDefaultNaye user ke liye
InpEnableGridtrueFalse = sirf first entry chalti hai, naye grid levels add nahi honge.
InpGridATRMult0.7Grid step = ATR × yeh number. Bada number = wide grid.
InpATRPeriod14ATR kitne bars se calculate ho.
InpEnableMinGapfalseChoppy market mein grid bahut tight na ho, iske liye minimum floor (pips).
InpMinGapPips10Minimum grid gap (pips).
InpEnableMaxGapfalseHigh volatility mein grid bahut wide na ho, iske liye upper cap.
InpMaxGapPips50Maximum grid gap (pips).
Naye users yahi galti karte hain: InpGridATRMult bahut chhota rakh dete hain — isse choppy market mein bahut zyada entries khul jaati hain. Pehle demo pe test karo.

SECTION 2 · IN DETAIL

ATR Grid System

The EA's core logic. Grid Step = ATR × Multiplier — the more volatile the market, the wider the grid. Min/Max Gap act as a safety clamp so the grid never gets too tight in choppy markets.
ParameterDefaultFor new users
InpEnableGridtrueFalse = only the first entry runs, no new grid levels get added.
InpGridATRMult0.7Grid step = ATR × this number. Higher number = wider grid.
InpATRPeriod14How many bars ATR is calculated over.
InpEnableMinGapfalseA floor so the grid never gets too tight in choppy markets (pips).
InpMinGapPips10Minimum grid gap (pips).
InpEnableMaxGapfalseA ceiling so the grid never gets too wide in high volatility.
InpMaxGapPips50Maximum grid gap (pips).
The most common new-user mistake: setting InpGridATRMult too small — this opens far too many entries in choppy markets. Test on demo first.

Lot Sizing & Martingale

Har grid level par kitna lot khulega — flat, exponential (Normal), ya linear growth. Normal mode: BaseLot × Factor^level. Linear mode: har N grid steps ke baad lot mein fixed increment.
ParameterDefaultNaye user ke liye
InpBaseLot0.01Pehle order ka lot size.
InpEnableMartingaletrueFalse = hamesha flat BaseLot, chahe mode kuch bhi ho.
InpMartingaleModeNormalNormal (exponential) ya Linear (steady) choose karo.
InpMartingaleFactor1.0Normal mode: multiply factor. 1.0 = koi martingale nahi.
InpMartingaleLinearIncrement0.01Linear mode: lot increment amount.
InpMartingaleStepGrids1Linear mode: har kitne grids baad increment lage.
InpMaxLotsPerDirection2.0Ek direction mein max total lots.
InpMaxTotalLots3.0Dono directions milakar max total lots.
Martingale risk badhata hai. InpMartingaleFactor ko 1.5+ rakhna sirf tabhi karo jab poori tarah samajh ke, aur hamesha InpMaxLotsPerDirection ek tight safety cap ke roop mein set karo.

SECTION 9

Daily Profit/Loss Limits

A daily $ profit target or loss limit — once hit, the EA pauses for that day and automatically resumes the next day.
ParameterDefaultFor new users
InpEnableDailyLimitsfalseON/OFF.
InpDailyProfitTarget100.0Daily profit target ($).
InpDailyLossLimit50.0Daily loss limit ($).
Unlike the Circuit Breaker, this is not permanent — it only applies for that trading day.
