Bridge Setup Guide

Wire TradingView alerts to your MT5 EA in 4 steps. Follow in order.

01
TradingView — Webhook URL
In your TradingView alert, set Webhook URL to:
https://ag-assistant-api.onrender.com/master/agbridge
Note: Replace agbridge with your strategy ID if AG Technicals gave you a custom one.
02
TradingView — Alert Message (JSON)
In the alert's Message box, paste this JSON exactly — edit values to match your strategy:
{ "secret": "YOUR_SECRET_KEY", "action": "buy", "symbol": "XAUUSD", "price": {{close}}, "swing_price": {{plot("Swing")}} }
• secret — must match exactly what AG Technicals set for your account
• action — must be buy or sell
• price — {{close}} fills automatically from your chart
• swing_price — optional, for SL placement. Remove if not used.
03
MT5 — Allow WebRequest
In MetaTrader 5: Tools → Options → Expert Advisors tab → check "Allow WebRequest for listed URL" → add this domain:
https://ag-assistant-api.onrender.com
Important: Domain only — no path at the end. MT5 blocks the EA from reaching the internet without this.
04
MT5 — EA Inputs
Attach the AG Bridge EA to your chart and enter these values in the EA input settings:
Input NameWhat To Enter
License IDYOUR-LICENSE-ID (provided by AG Technicals)
Server URLhttps://ag-assistant-api.onrender.com
AccountFilled automatically from your MT5 terminal
05
What The EA Gets Back (Reference)
The EA polls GET /api/pull/{license_id} and receives plain text responses:
ResponseMeaning
OK|License activated...First call — license bound to this account
buy,XAUUSD,2634.5,...Signal waiting — EA will execute trade
(empty)No signal pending — EA keeps polling
ERROR|License locked...Wrong MT5 account for this license
ERROR|Subscription expiredLicense has expired — contact AG Technicals to renew
✓
Pre-Live Checklist
■Webhook URL set correctly in TradingView alert
■JSON message has correct secret, action, and symbol
■MT5 WebRequest URL added in Tools → Options
■License ID and Server URL entered in EA inputs
■EA attached to chart and AutoTrading enabled in MT5
■Test alert sent from TradingView — check MT5 journal for "License activated"
